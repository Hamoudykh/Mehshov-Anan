# Tutorial 2 – JSON in Colab

Intro to Cloud Computing, Braude. Muhammad Khamra & Hamdan Khatib.

## Files
- `Tutorial2_JSON_students_form.ipynb` – the Colab notebook (Drive mount, creating `students.json`, the form).
- `students.json` – the group's details, one JSON object per student.

## How to run
1. Open the notebook in Google Colab (File → Upload notebook, or open it from GitHub).
2. Run the cells top to bottom and allow Drive access when asked.
3. Step 2 creates `students.json` in the root of My Drive if it isn't there yet.
4. In the form, pick a student from the dropdown to see their details.
5. Type a favorite program and press **Update**. The student's record in `students.json` is updated.
6. Run the last cell to see the updated file.
